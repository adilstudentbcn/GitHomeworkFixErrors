# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

JavaScript is a programming language used to build interactive websites

## 3. What three problems does Git & GitHub solve?

 Version Control, collaboration, and remote backup.


## 4. What happens when you `fork` a repository?

You create a copy of a repository. You can make changes without affecting the original project.


## 5. What happens when you clone a repository?

You download a copy of that repository to your computer.

## 6. What is a Pull Request?

It’s a request to merge your work / code changes into another repository.
